# V3 - Segmentación por cliente

Marketing necesita poder crear cupones destinados solamente a determinados
clientes.

Para representar esta segmentación se incorpora el campo opcional:

- `allowedUserIds`

Los cupones que no tengan segmentación deben continuar pudiendo utilizarse como
cupones generales.

Esta nueva condición debe integrarse con las reglas de elegibilidad y uso que ya
posee la funcionalidad.

Los cupones existentes deben continuar siendo compatibles.
