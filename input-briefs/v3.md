# V3 - Restricción de cupones por usuario

La funcionalidad de cupones debe permitir restringir determinados cupones a usuarios específicos.

## Cambio solicitado

Un cupón podrá definir opcionalmente una lista de usuarios habilitados.

- Si el cupón posee una lista de usuarios, únicamente esos usuarios podrán utilizarlo.
- Si el cupón no posee una lista de usuarios, podrá ser utilizado por cualquier usuario que cumpla las demás reglas.
- Un intento realizado por un usuario no habilitado debe ser rechazado.
- Un intento rechazado por esta condición no debe consumir un uso del cupón.
- Estar incluido en la lista no evita las demás validaciones del cupón.

Todos los requerimientos anteriores que no sean modificados explícitamente deben continuar vigentes.

## Extensión de la API

A partir de V3, POST /coupons podrá incluir opcionalmente:

{
"allowedUserIds": [1, 2]
}

Si `allowedUserIds` no se proporciona o se encuentra vacío, el cupón no tendrá
restricción por usuario.
