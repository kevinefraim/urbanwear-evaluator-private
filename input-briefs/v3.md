# V3 - Segmentación por cliente

Marketing necesita poder limitar determinados cupones a clientes específicos.

Para representar esta condición se incorpora el campo opcional:

- `allowedUserIds`

Los cupones que no tengan segmentación deben continuar siendo generales.

La nueva condición debe integrarse con todas las reglas de elegibilidad y uso
que ya posee la funcionalidad.

Los cupones y comportamientos existentes deben continuar siendo compatibles.
