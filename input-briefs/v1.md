# V1 - Cupones de descuento

Marketing necesita incorporar cupones al checkout de UrbanWear.

Los cupones deben permitir descuentos porcentuales o de monto fijo y contemplar
condiciones comerciales como vigencia, monto mínimo y categorías aplicables.

También debe evitarse la reutilización indebida de un mismo cupón por un cliente.

Se necesita:

- crear cupones mediante `POST /coupons`;
- consultar un cupón mediante `GET /coupons/:code`;
- aplicar opcionalmente un cupón durante `POST /checkout/:userId`.

La creación de un cupón utiliza:

- `code`
- `type`
- `value`
- `validFrom`
- `validUntil`
- `minimumAmount`
- `categoryIds`

El checkout recibe opcionalmente:

- `couponCode`

La implementación debe integrarse con el checkout y la persistencia existente,
sin romper el comportamiento actual cuando no se utiliza un cupón.

No se requiere frontend.
