# V1 - Cupones de descuento

UrbanWear debe incorporar una funcionalidad de cupones aplicable durante el checkout.

## API

### Crear cupón

POST /coupons

El cupón debe permitir definir:

- code: código único;
- type: `percentage` o `fixed`;
- value: valor del descuento;
- validFrom: fecha inicial de vigencia;
- validUntil: fecha final de vigencia;
- minimumAmount: monto mínimo de compra;
- categoryIds: categorías sobre las cuales puede aplicarse.

### Consultar cupón

GET /coupons/:code

### Aplicar cupón

POST /checkout/:userId

El body puede incluir:

{
"couponCode": "URBAN20"
}

La respuesta de un checkout exitoso con cupón debe informar:

- subtotal;
- discount;
- total;
- couponCode.

## Reglas funcionales

1. Un cupón puede aplicar un descuento porcentual o de monto fijo.

2. Los descuentos porcentuales deben estar entre 1 y 100.

3. El total final nunca puede ser negativo.

4. El cupón solo puede utilizarse dentro de su período de vigencia. Las fechas
   inicial y final se consideran incluidas.

5. El monto mínimo se evalúa sobre el subtotal completo del carrito antes de
   aplicar el descuento.

6. Un cupón puede restringirse a una o más categorías.

7. Si el carrito contiene productos de categorías permitidas y no permitidas,
   el descuento se aplica únicamente sobre los productos pertenecientes a las
   categorías permitidas.

8. Si el cupón no posee restricciones de categoría, el descuento se aplica
   sobre todos los productos del carrito.

9. Si ningún producto del carrito pertenece a una categoría permitida, el
   cupón debe ser rechazado.

10. En esta versión, cada usuario puede utilizar un mismo cupón una sola vez.

11. Un uso se registra únicamente cuando el checkout finaliza correctamente.
    Los intentos rechazados no consumen el cupón.

12. El uso de un cupón por parte de un usuario no afecta su disponibilidad
    para otros usuarios.

13. Solo puede aplicarse un cupón por checkout.

14. Un checkout sin cupón debe continuar funcionando igual que antes de
    incorporar esta funcionalidad.

## Persistencia

La información de cupones y de sus utilizaciones debe persistir en SQLite.
