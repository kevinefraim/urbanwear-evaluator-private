# V1 - Cupones de descuento

Marketing necesita incorporar cupones al checkout de UrbanWear.

Los cupones deben permitir descuentos porcentuales o de monto fijo y contemplar
condiciones comerciales como vigencia, monto mínimo y categorías aplicables.

También debe existir algún control sobre la reutilización de un cupón por parte
de un mismo cliente.

Se necesita:

- crear cupones mediante `POST /coupons`;
- consultar un cupón mediante `GET /coupons/:code`;
- aplicar opcionalmente un cupón durante `POST /checkout/:userId`.

La creación utiliza los siguientes campos:

- `code`
- `type`
- `value`
- `validFrom`
- `validUntil`
- `minimumAmount`
- `categoryIds`

El checkout recibe opcionalmente:

- `couponCode`

Cuando el checkout utiliza exitosamente un cupón, la respuesta debe incluir:

- `subtotal`
- `discount`
- `total`
- `couponCode`

La funcionalidad debe integrarse con la persistencia y el checkout existentes.

El checkout sin cupón debe continuar funcionando.

No se requiere frontend.
