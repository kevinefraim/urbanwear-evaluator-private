# V2 - Evolución del límite de uso de cupones

La funcionalidad de cupones debe modificar la política de utilización por usuario.

## Cambio solicitado

Actualmente, cada usuario puede utilizar un mismo cupón una única vez.

A partir de esta versión:

- cada usuario podrá utilizar un mismo cupón hasta tres veces en total;
- un mismo usuario no podrá utilizar el mismo cupón más de una vez durante el mismo día calendario;
- podrá volver a utilizarlo en días posteriores mientras no haya alcanzado el máximo de tres usos;
- los usos de distintos usuarios deben continuar contabilizándose de forma independiente;
- los intentos de checkout rechazados no deben consumir usos.

Todos los demás comportamientos definidos en V1 deben continuar vigentes.
